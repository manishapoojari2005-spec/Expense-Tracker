# Expense Tracker

## Project Description

A simple web-based Expense Tracker that helps users record and manage their daily expenses.

## Features

- Add expenses
- Enter expense amount
- Select expense category
- Calculate total expenses
- Display expense history
- Simple and user-friendly interface

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

Open the `index.html` file in a web browser.
